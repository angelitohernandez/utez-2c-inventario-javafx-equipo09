# INVENTARIO DE PRODUCTOS (Tienda)

# 📝 Descripción del Sistema
Este es un programa desarrollada en JavaFX diseñada para una tiendita local. El sistema permite administrar el inventario de productos de forma eficiente sin necesidad de bases de datos.

# Características principales (CRUD):
Alta: Registro de nuevos productos con validación de código único.
Consulta:Visualización de productos en una tabla y una barra de busqueda.
Actualización: Modificación de datos de productos existentes.
Eliminación: Borrado de productos con confirmación de seguridad.
Persistencia: Guardado automático en un archivo local.
